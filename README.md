One sentence, 148 characters, explaining the modern internet to a time traveler from 1800 — built only from things they already know: a road, a library, a letter, ink. Any house on the road can open the great library, and a letter written in London is read in Canton, and answered, before its ink has dried.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

Writes one sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (pure stdlib, no network).
